b. Perangkat Wireless & Antena

Fungsi perangkat utama (Access Point vs Router) serta jenis antena directional vs omnidirectional.

Access Point (AP) Standalone

Perangkat Layer 2 (Data Link) yang berfungsi seperti hub nirkabel. Menghubungkan client nirkabel ke jaringan kabel LAN lokal. Tidak melakukan fungsi routing, NAT, atau DHCP Server secara mandiri.

  • Fokus pada coverage & roaming skala besar (kantor/sekolah).
  • Membutuhkan Router terpisah untuk pembagian IP Address.
  • Mendukung PoE (Power over Ethernet).

Wireless Router / Broadband Router

Perangkat multifungsi gabungan antara **Router (Layer 3)**, **Switch 4-Port**, **Access Point**, serta **DHCP & Firewall/NAT Server**.

  • Cocok untuk jaringan SOHO (Small Office / Home Office).
  • Memiliki Port WAN (Internet) dan LAN.
  • Menyediakan fitur Bandwidth Limiter & Parental Control.

Klasifikasi Antena Nirkabel

Omnidirectional

Antena Omni (360°)

Pancaran sinyal menyebar ke segala arah secara horizontal. Cocok untuk indoor AP & area terpusat.

Gain: 3 - 15 dBi
Jangkauan: Point-to-Multipoint (P2MP)
Semi-Directional

Sectoral / Patch / Panel

Pancaran sinyal memancar ke sudut tertentu (misal 60°, 90°, atau 120°). Biasa terpasang di tower BTS/WISP.

Gain: 12 - 20 dBi
Jangkauan: Cakupan Sektor Spesifik
Directional

Grid / Dish / Yagi

Fokus sinyal sangat sempit namun berjarak sangat jauh. Sangat cocok untuk koneksi tembak antar gedung (PtP).

Gain: 20 - 30+ dBi
Jangkauan: Point-to-Point (PTP) Jarak Jauh

Omnidirectional Pola 2D Horizontal

Antena Omnidirectional (360°)

Memancarkan sinyal gelombang radio secara seragam ke segala arah secara horizontal (360 derajat), membentuk pola menyerupai kue donat.

Sudut Pancar (Beamwidth): 360° Horizontal
Cakupan Jangkauan: Area Sekitar AP (~100m)
Tipe Koneksi: Point-to-Multipoint (P2MP)
Tips Pemasangan TKJ: Pasang antena omni di posisi tengah ruangan / ceiling gedung untuk pemerataan sinyal ke seluruh perangkat client.

d. Perawatan & Troubleshooting Jaringan

Metodologi diagnosa kerusakan fisik (kabel/hardware) vs kerusakan logis (konfigurasi IP/SSID).

Perawatan Preventif (Pencegahan)

  • Pembersihan Debu Fisik: Rutin membersihkan ventilasi Access Point dari debu agar tidak *overheating*.
  • Update Firmware: Memperbarui versi OS/firmware router secara berkala untuk menutupi *security vulnerability*.
  • Backup Konfigurasi: Mengekspor file konfigurasi (.backup/.cfg) router secara tertib.

Troubleshooting Korektif (Perbaikan)

  • Layer 1 (Fisik): Cek indikator lampu LED LAN/PoE, kualitas crimping RJ45 dengan LAN Tester, dan adaptor daya.
  • Layer 2 (Data Link): Periksa kesesuaian Password WPA2/WPA3, Hiding SSID, serta sertifikat autentikasi.
  • Layer 3 (Network): Pengecekan IP Conflict, subnetting, ketersediaan alokasi IP DHCP, serta tes `ping`.

Lembar Kerja Praktikum LAB TKJ

Topik: Konfigurasi Access Point & Analisis Interferensi Sinyal

A. Alat dan Bahan:

  • 1 Unit Wireless Router / Access Point (TP-Link / MikroTik / Cisco)
  • 2 Unit Kabel UTP Patch Cord Straight-through
  • 1 Unit Laptop / PC Client
  • Aplikasi Wi-Fi Analyzer (Smartphone / PC)

B. Langkah Kerja:

  1. Hubungkan port LAN PC ke port LAN Access Point menggunakan kabel UTP.
  2. Atur IP PC Client satu subnet dengan IP default Access Point (misal: 192.168.1.2).
  3. Buka web browser dan akses IP Web GUI Router (192.168.1.1).
  4. Konfigurasikan **SSID** dengan format TKJ_NAMA_SISWA.
  5. Aktifkan enkripsi **WPA2-PSK** dan tentukan password minimal 8 karakter.
  6. Aktifkan **DHCP Server** dengan range IP 192.168.1.10 - 192.168.1.50.
  7. Uji koneksi nirkabel menggunakan Smartphone/PC lain dan lakukan perintah ping 192.168.1.1.
